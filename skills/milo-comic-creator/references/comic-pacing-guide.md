# Comic Pacing & Sequential Storytelling Guide

## 1. โครงสร้างการเล่าเรื่องการ์ตูน 4 ช่อง (The 4-Beat Pacing / Kishōtenketsu)

เพื่อให้เรื่องราวการ์ตูนของไมโลอ่านสนุก ลื่นไหล และมีจังหวะตบมุกหรือความประทับใจที่ลงตัว ให้ใช้โครงสร้าง 4 จังหวะเป็นแกนหลัก:

```text
┌─────────────────┐  ┌─────────────────┐
│     ช่อง 1       │  │     ช่อง 2       │
│  起 (Ki): เกริ่น   │  │  承 (Shō): เดินเรื่อง│
└─────────────────┘  └─────────────────┘
┌─────────────────┐  ┌─────────────────┐
│     ช่อง 3       │  │     ช่อง 4       │
│  転 (Ten): พลิกผัน │  │  結 (Ketsu): สรุปมุก │
└─────────────────┘  └─────────────────┘
```

1. **ช่อง 1: เกริ่นนำ (Setup - 起)**
   - แนะนำฉาก สิ่งแวดล้อม และสิ่งที่ไมโลตั้งใจจะลองทำ
   - มักใช้ภาพมุมกว้าง (Wide Shot) หรือภาพระดับกลาง (Medium Shot) เพื่อให้เห็นบริบท
   - อารมณ์ของไมโล: มุ่งมั่น สดใส มั่นใจ พร้อมลุย
2. **ช่อง 2: ดำเนินเรื่อง (Development - 承)**
   - ไมโลลงมือทำตามขั้นตอนอย่างขะมักเขม้น หรือคำนวณตามตำรา
   - แสดงรายละเอียดแอ็กชันและอุปกรณ์
   - อารมณ์ของไมโล: ตั้งใจสูง สมาธิจดจ่อ
3. **ช่อง 3: จุดพลิกผัน / เซอร์ไพรส์ (Twist/Climax - 転)**
   - เกิดเหตุการณ์ไม่คาดฝัน ข้อผิดพลาดน่ารักๆ หรือการค้นพบที่ผิดแผน
   - ปรับมุมกล้องให้ตื่นเต้น เช่น ซูมหน้าโคลสอัพ (Extreme Close-up) หรือมุมเอียง (Dutch Tilt)
   - อารมณ์ของไมโล: ตกใจ เบิกตากว้าง สับสน หรือตัวลอย
4. **ช่อง 4: บทสรุป / ตบท้าย (Resolution & Punchline - 結)**
   - ผลลัพธ์สุดท้ายที่ตลก อบอุ่น หรือสะท้อนบทเรียนแบบไม่เทศนา
   - เคลียร์ความตึงเครียดจากช่อง 3
   - อารมณ์ของไมโล: ยิ้มตาหยี หัวเราะ หรือเกาหัวแก้เขิน

## 2. การสลับมุมกล้อง (Shot Variety) เพื่อความลื่นไหล

อย่าใช้มุมกล้องเดิมซ้ำกันทุกช่อง ให้สลับมุมมองเพื่อสร้างไดนามิก:

- **ช่อง 1 (Establishing):** Wide Shot — เห็นไมโลและสภาพแวดล้อมโดยรวม
- **ช่อง 2 (Action):** Medium Shot — โฟกัสที่การจับอุปกรณ์หรือการขยับตัว
- **ช่อง 3 (Reaction / Peak):** Close-Up หรือ Dynamic Angle — โฟกัสที่เอฟเฟกต์ ความตื่นเต้น และการแสดงอารมณ์ทางสายตา
- **ช่อง 4 (Payoff):** Medium / Wide Shot — สรุปภาพรวมของผลลัพธ์พร้อมรีแอ็กชันสุดท้าย

## 3. องค์ประกอบตัวหนังสือและการนำสายตา (Eye-flow & Lettering)

- **ลำดับการอ่าน (Z-Path):** จัดวางคำบรรยาย/บอลลูนให้อ่านจาก ซ้ายบน ➔ ขวาบน ➔ ซ้ายล่าง ➔ ขวาล่าง
- **กล่องคำบรรยาย (Caption Box):** ใช้สี่เหลี่ยมผืนผ้าขอบมนสั้นๆ สำหรับบอกเวลาหรือความคิดเล่าเรื่อง เช่น *"บ่ายวันหนึ่ง...", "คำนวณเป๊ะ 100%..."*
- **บอลลูนคำพูด (Speech Balloons):** บอลลูนกลมมนชี้ไปยังไมโลหรือตัวละคร
- **เอฟเฟกต์เสียง (SFX Lettering):** ตัวอักษรศิลป์ขนาดใหญ่เพื่อเพิ่มอรรถรส เช่น `*แชะ!*`, `*หวืดดด!*`, `*เป๊าะ!*`, `*จ๋อม!*`
